# NVDA Volume Adjustment (Регулювання гучності)

* Автор: Олександр Грищенко
* Версія: 2.0
* Сумісність з NVDA: 2026.1 та новіші версії
* Встановлення: через Магазин додатків NVDA ([стабільна версія][1])

Регулюйте гучність кожного аудіопристрою та кожної запущеної програми окремо, перемикайте пристрій виводу NVDA та аудіопристрої Windows за замовчуванням і приглушуйте свої мікрофони в усіх програмах одночасно - усе це з клавіатури.

## Комбінації клавіш
Після встановлення додаток не має комбінацій клавіш. Ви можете:

* увімкнути передвстановлені комбінації клавіш опцією "Використовувати комбінації клавіш за замовчуванням" у налаштуваннях додатку, або
* призначити власні комбінації клавіш будь-якій команді в діалозі NVDA "Жести вводу", у категорії "Регулювання гучності".

У цьому документі згадано передвстановлені комбінації клавіш. Усі вони починаються з NVDA+Windows, тому їх легко запам'ятати і вони не конфліктують з іншими командами.

## Джерела звуку
Додаток працює з чотирма категоріями джерел звуку, завжди в такому порядку:

1. пристрої виводу (динаміки, навушники);
2. пристрої вводу (мікрофони, лінійні входи);
3. програми відтворення - програми, що відтворюють звук;
4. програми запису - програми, що записують звук.

Усі аудіосесії програми регулюються разом, навіть якщо програма відтворює звук на кількох пристроях одночасно. Програма, яка і відтворює, і записує звук, наприклад відеодзвінок, з'являється в обох категоріях програм.

* NVDA+Windows+Стрілка вправо або Стрілка вліво - вибрати наступне або попереднє джерело звуку. Список циклічний.
* NVDA+Windows+Control+Стрілка вправо або Стрілка вліво - перейти до першого джерела звуку наступної або попередньої категорії.
* NVDA+Windows+O, I, P або R - показати або приховати пристрої виводу, пристрої вводу, програми відтворення або програми запису. Коли категорію показано, оголошується кількість її джерел.
* NVDA+Windows+Shift+O, I, P або R - показати лише цю категорію.

Останню видиму категорію приховати неможливо. Назва категорії оголошується, коли ви переходите до неї; це можна вимкнути в налаштуваннях додатку.

За замовчуванням команди гучності регулюють програму у фокусі. Якщо вона не відтворює звуку, додаток повідомляє про це і нічого не змінює. Коли ви вибираєте інше джерело стрілками, воно залишається вибраним, доки фокус не перейде до іншої програми; вікна самої NVDA, наприклад налаштування додатку, не враховуються. Якщо вибраний пристрій відключено, вимкнено або приховано, додаток повідомляє, що він недоступний, і пристрій знову регулюватиметься, щойно він стане доступним.

Коли ви вибираєте джерело, його назва оголошується разом з рівнем гучності. Брайлівський дисплей показує їх у скороченому вигляді, наприклад "Динаміки: 30%".

## Регулювання гучності
* NVDA+Windows+Стрілка вгору або Стрілка вниз - збільшити або зменшити гучність.
* NVDA+Windows+Home - встановити максимальну гучність. Будьте обережні: раптовий гучний звук може пошкодити слух.
* NVDA+Windows+End - встановити мінімальну гучність.
* NVDA+Windows+Escape - приглушити джерело або відновити його гучність.

Зменшення гучності до нуля приглушує джерело. Приглушення може повністю вимикати звук або лише зменшувати гучність на певний відсоток; режим вибирається в налаштуваннях додатку.

## Канали
* NVDA+Windows+Shift+Стрілка вправо або Стрілка вліво - вибрати наступний або попередній канал вибраного джерела. Канали нумеруються з 1.
* NVDA+Windows+Shift+Стрілка вгору або Стрілка вниз - збільшити або зменшити гучність вибраного каналу.
* NVDA+Windows+Shift+Home або End - встановити максимальну або мінімальну гучність вибраного каналу.
* NVDA+Windows+Shift+Escape - встановити для всіх каналів їхню середню гучність.

Канали програм можна регулювати лише тоді, коли розділення звуку NVDA вимкнено, оскільки розділення звуку використовує ті самі канали. Інакше додаток повідомить, що канали використовуються розділенням звуку.

## Захист гучності NVDA
Сама NVDA також є програмою відтворення. Перш ніж ви зменшите або приглушите її гучність чи один з її каналів, додаток запитує підтвердження, оскільки NVDA може замовкнути, а Windows запам'ятовує її гучність навіть після перезапуску NVDA. Попередження можна вимкнути в самому діалозі або в налаштуваннях додатку.

## Пристрої виводу
Три групи команд використовують ті самі клавіші, F1-F12, PageUp і PageDown:

* NVDA+Windows - пристрій виводу мовлення та звуків NVDA;
* NVDA+Windows+Shift - пристрій виводу Windows за замовчуванням;
* NVDA+Windows+Control - пристрій зв'язку Windows за замовчуванням.

З кожною групою:

* F1-F12 - перемкнутися на пристрій виводу з 1-го по 12-й. Ці команди створюються для пристроїв виводу, знайдених під час запуску NVDA: пристрій, підключений пізніше, отримує власну команду після перезапуску NVDA. Команда для пристрою, який було відключено, повідомляє, що пристрій недоступний.
* PageUp або PageDown - перемкнутися на наступний або попередній пристрій виводу. Ці команди завжди використовують пристрої, доступні в цей момент, зокрема й підключені пізніше.

Команди для кожного окремого пристрою наведено в діалозі NVDA "Жести вводу" з назвами пристроїв, тому ви можете призначити їм інші комбінації клавіш.

* NVDA+Windows+D - повернути NVDA на пристрій виводу за замовчуванням, щоб вона слідувала за пристроєм Windows за замовчуванням.
* NVDA+Windows+S - відкрити діалог "Звук" Windows.

## Пристрої вводу
Дві групи команд використовують цифрові клавіші 1-9 і 0, щоб перемкнутися на пристрій вводу з 1-го по 10-й:

* NVDA+Windows+Shift - пристрій вводу Windows за замовчуванням;
* NVDA+Windows+Control - пристрій вводу для зв'язку Windows за замовчуванням.

Ці команди створюються для пристроїв вводу, знайдених під час запуску NVDA: пристрій, підключений пізніше, отримує власні команди після перезапуску NVDA. Команда для пристрою, який було відключено, повідомляє, що пристрій недоступний. Команди для кожного окремого пристрою наведено в діалозі NVDA "Жести вводу" з назвами пристроїв, тому ви можете призначити їм інші комбінації клавіш.

## Швидке приглушення мікрофонів
NVDA+Windows+Пробіл приглушує або вмикає у Windows усі мікрофони, вибрані в налаштуваннях додатку, тож кожна програма отримує тишу: відеодзвінки, месенджери, програми запису та інші. Вам не потрібно запам'ятовувати окрему комбінацію клавіш у кожній програмі.

Якщо будь-який з вибраних мікрофонів увімкнено, усі вони приглушуються; інакше всі вони вмикаються. Короткий звук відтворюється після приглушення та перед увімкненням, тож мікрофони його не записують. Мікрофони ніколи не вмикаються автоматично під час завершення роботи NVDA.

## Налаштування додатку
* Повідомляти про стан джерела звуку під час перемикання - оголошувати гучність або стан приглушення джерела чи каналу, коли його вибрано.
* Оголошувати назви категорій під час перемикання - оголошувати категорію, коли ви переходите до неї стрілками.
* Оголошувати подробиці про аудіопристрій - після рівня гучності або назви аудіопристрою оголошувати його тип (наприклад, навушники чи мікрофон), підключення (USB, Bluetooth або віртуальне) та те, чи є він пристроєм Windows за замовчуванням.
* Видимі категорії джерел звуку - категорії, між якими ви перемикаєтеся, так само як за допомогою NVDA+Windows+O, I, P і R.
* Крок зміни рівня гучності, % - на скільки одне натискання змінює гучність, від 1 до 20 відсотків.
* Оголошувати рівень гучності в - відсотках, відсотках без знака відсотка або децибелах для аудіопристроїв. Гучність програм завжди оголошується у відсотках. Значення в децибелах надає пристрій та його драйвер, тому вони інколи можуть виглядати незвично, наприклад вузький діапазон або значення набагато нижчі за нуль.
* Змінювати гучність поточної програми - команди гучності регулюють програму у фокусі. Коли цю опцію вимкнено, вони регулюють перше джерело у списку, зазвичай пристрій виводу за замовчуванням, доки ви не виберете інше джерело стрілками.
* Приховати пристрої виводу, Приховати пристрої вводу, Приховати процеси - елементи, які ви не хочете бачити у списку джерел звуку. Кнопка "Оновити" оновлює список і зберігає позначені елементи; кнопка "Очистити" знімає позначки з усіх елементів і вилучає ті, яких уже немає.
* Режим приглушування - "Повне вимкнення звуку" вимикає звук; "Зменшення гучності на встановлене значення" зменшує гучність на відсоток, встановлений повзунком "Зменшувати гучність на величину у відсотках".
* Вмикати всі приглушені аудіоресурси при завершенні роботи NVDA - відновлювати гучність джерел, приглушених додатком, під час завершення роботи NVDA. Відновити можна лише програми, запущені в цей момент, і пристрої, підключені в цей момент. Джерела, приглушені у Windows, і мікрофони швидкого приглушення залишаються приглушеними.
* Попереджати перед зменшенням або приглушенням гучності самої NVDA - див. "Захист гучності NVDA".
* Мікрофони швидкого приглушення - мікрофони, які приглушуються та вмикаються за допомогою NVDA+Windows+Пробіл.
* Використовувати комбінації клавіш за замовчуванням - увімкнути або вимкнути передвстановлені комбінації клавіш. Щоб зміна набула чинності, додатки потрібно перезавантажити: ви можете перезавантажити їх одразу або вибрати перезавантаження пізніше, і тоді зміна набуде чинності після перезапуску NVDA.

## Внесення змін до вихідного коду додатку
Ви можете клонувати цей репозиторій, щоб внести зміни до NVDA Volume Adjustment.

Вимоги:

* [uv](https://docs.astral.sh/uv/) - керує Python та всіма інструментами розробки додатку;
* [GNU Gettext tools](https://mlocati.github.io/articles/gettext-iconv-windows.html) (`msgfmt` і `xgettext` у `PATH`) - компілюють переклади та створюють шаблон рядків для перекладу.

Виконайте такі команди з кореня репозиторію:

1. `uv sync` - встановити залежності для розробки;
2. `uv run prek run --all-files` - запустити всі перевірки коду: лінтинг і форматування за допомогою ruff, перевірку типів за допомогою pyright та інші перевірки;
3. `uv run python -m unittest discover -s tests -v` - запустити модульні тести;
4. `uv run scons` - зібрати додаток, створений файл `.nvda-addon` розміщується в корені репозиторію;
5. `uv run scons pot` - створити файл `.pot` з усіма рядками додатку для перекладу (необов'язково).
